## 3. Third-Party Names and Marks in Source

### Mastercard
| Item | Location | Context | Status |
|------|----------|---------|--------|
| Mastercard-style dual-circle mark | src/components/patterns/bank-card.tsx | SVG inline circle + oval — mimics Mastercard mark in demo UI | ⚠️ **Review required** |

**Detail:** The bank-card pattern renders an SVG that resembles the Mastercard logo (two overlapping circles in red/orange). This is drawn programmatically — it is NOT an official Mastercard asset file. However, use of a mark that could be confused with a registered trademark may require licensing or explicit disclaimer.

**Recommendation:** 
- Before shipping to production, either (a) obtain Mastercard's acceptance mark usage permission, or (b) replace with an abstract payment card design that does not resemble any specific payment network.
- The design system preview uses this for demonstration only — this is acceptable for internal dev tools.
- DO NOT include in any marketing material or public-facing product without Mastercard approval.

### ShebaMiles (Ethiopian Airlines Loyalty Program)
| Item | Location | Context | Status |
|------|----------|---------|--------|

**Detail:** ShebaMiles is a registered trademark of Ethiopian Airlines. Used in preview demos as fictitious data. Must NOT appear in production UI unless a formal partnership agreement is in place.

**Recommendation:** Replace with fictional loyalty program name in demos (e.g., "Samra Rewards" or "Habesha Miles" — verify trademark clearance).

## 4. Pattern Utilities

| Asset | Location | Source | Status |
|-------|----------|--------|--------|
| Ethiopian patterns (telsem, axum, tibeb, mesob) | scripts/theme-template.css | CSS-generated, inspired by traditional Ethiopian design | ✅ Safe |

**Detail:** All patterns are generated from CSS `radial-gradient`, `linear-gradient`, and `repeating-linear-gradient` calls. No image assets are involved. The patterns are inspired by traditional Ethiopian cultural motifs — CSS-generated geometry is not protectable IP.

**Note:** If the design system is ever formally published to a package registry, consider adding a README note crediting the cultural inspiration sources (Aksumite architecture, tibeb weaving, etc.) as a matter of cultural respect.
